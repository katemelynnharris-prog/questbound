# Quest conventions

When the user says daily, use daily reset availability. Daily never implies placement in the Daily Ledger.
Only set recurrence.daily_ledger to true when the user explicitly asks for the Ledger. New editor entries default to false.
For optional once-per-day opportunities use repeatable recurrence; independent progress uses completion_scope: player.
Household tasks share a completion and reward the completer. Co-op tasks share a completion and reward both members.
Training Extra Effort is optional, separate per player, and claimable once after completing today's assigned workout.
